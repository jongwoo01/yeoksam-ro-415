# 강남 역삼로 415 성진빌딩 실제로 걸어보기

Blender와 Three.js로 제작한 강남 역삼로 415 성진빌딩 주변의 3인칭 거리 산책입니다. 항공뷰에서 입장해 이디야 앞 대로와 소풍 옆 차도, 뒤편 주차장, 서측 진입로와 맞은편 골목을 걸을 수 있습니다. 건물과 차량의 크기는 거리에서 보이는 비례를 바탕으로 재구성했습니다.

## 실행

Node.js 20 이상에서 `node build.mjs`를 실행하고 `dist`를 정적 서버로 엽니다. 예를 들어 `python3 -m http.server 8080 --directory dist`를 실행하면 됩니다. 배포 빌드는 장면을 무손실 gzip으로 압축합니다.

## 조작

WASD 또는 방향키로 이동하고 마우스로 둘러봅니다. Shift로 달리고 Space로 점프합니다. Esc 또는 왼쪽 위 설정 버튼으로 캐릭터 선택, 조작법, 위치 이동 메뉴를 엽니다.

터치 화면에서는 왼쪽 조이스틱으로 걷거나 달리고 화면을 밀어 시점을 돌립니다. 바닥을 짧게 탭하면 그곳까지 자동으로 이동합니다. 화면 오른쪽 아래 버튼으로 점프합니다. 산책 구역 끝에 접근하면 서로 이어진 오각형 무늬의 반투명 경계가 보입니다.

## 제작 자료
