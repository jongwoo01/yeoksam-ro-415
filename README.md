# 한큐 거리 산책

Blender와 Three.js로 제작한 한큐컴퍼니 주변의 3인칭 거리 산책입니다. 항공뷰에서 입장해 이디야 앞과 뒤편 주차장 사이를 걸을 수 있습니다. 건물과 차량의 크기는 거리에서 보이는 비례를 바탕으로 재구성했습니다.

## 실행

Node.js 20 이상에서 `node build.mjs`를 실행하고 `dist`를 정적 서버로 엽니다. 예를 들어 `python3 -m http.server 8080 --directory dist`를 실행하면 됩니다. 배포 빌드는 장면을 무손실 gzip으로 압축합니다.

## 조작

WASD 또는 방향키로 이동하고 마우스로 둘러봅니다. Shift로 달리고 Space로 점프합니다. Esc로 커서를 풀면 장소 이동이나 캐릭터 선택을 사용할 수 있습니다.

## 제작 자료

Three.js와 관련 로더의 라이선스는 MIT입니다. 거리 재질과 맨홀 모델에 Poly Haven의 CC0 자료를 사용했습니다. Blender 제작 스크립트는 source에, 웹에서 사용하는 완성 모델과 애니메이션은 public에 있습니다.
